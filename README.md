## Installation

   ```bash

   cd agent_rs
   ```

2. **Set Up Environment Variables**

   Create a `.env` file in the root directory and add your API keys:

3. **Build the Project**

   ```bash
   cargo build --release
   ```

4. **Run the Project**

   ```bash
   cargo run --release
   ```

## Configuration

The application uses a configuration structure to manage API endpoints, keys, and models. You can modify the configuration directly in the `main` function or extend the `LLMConfig` struct as needed.

```rust
#[derive(JsonSchema, Serialize, Deserialize, Default, Debug, Clone, Copy)]
enum TemperatureUnit {
    #[serde(rename = "celsius")]
    Celsius,
    #[default]
    #[serde(rename = "fahrenheit")]
    Fahrenheit,
}

#[derive(JsonSchema, Serialize, Deserialize, Debug)]
struct WeatherParams {
    #[schemars(description = "City and state")]
    location: String,

    #[schemars(description = "Temperature unit")]
    #[serde(default)]
    unit: TemperatureUnit,
}
```

## Usage

### Defining and Executing Functions

The framework allows you to define functions that the agent can execute based on user input. Below is an example of defining a weather function and integrating it into the agent's workflow.

```rust
async fn get_weather(location: &str, unit: TemperatureUnit) -> serde_json::Value {
    // Mock weather data - replace with real API call in production
    serde_json::json!({
        "location": location,
        "temperature": 72,
        "unit": unit,
        "forecast": ["sunny", "windy"],
        "humidity": 65
    })
}
```

### Making API Requests

The framework uses `reqwest` to make HTTP requests to the configured API endpoints.

```rust
let client = reqwest::Client::new();
let response = client
    .post(&config.base_url)
    .headers(headers.clone())
    .json(&request)
    .send()
    .await?;
```

### Handling Responses

Responses are parsed and processed to extract relevant information or execute functions.

```rust
let parsed_response: Result<LLLMResponse, serde_json::Error> =
    serde_json::from_str(&response_text);

let response_data = match parsed_response {
    Ok(response_data) => response_data,
    Err(err) => {
        bail!("Failed to parse, Error: {}, JSON: {}", err, response_text);
    }
};
```

## Project Structure

```
agent_rs/
├── Cargo.toml
├── README.md
├── .env
└── src
    ├── main.rs
    ├── function.rs
    ├── llm_config.rs
    ├── message.rs
    ├── request.rs
    └── response.rs
```

- **main.rs:** Entry point of the application, handling the overall workflow.
- **function.rs:** Defines functions that the agent can execute.
- **llm_config.rs:** Configuration structures for the language model.
- **message.rs:** Structures for handling different types of messages.
- **request.rs:** Structures for building and managing API requests.
- **response.rs:** Structures for parsing and managing API responses.
